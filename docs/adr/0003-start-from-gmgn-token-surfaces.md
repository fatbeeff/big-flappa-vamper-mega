# Start from GMGN token surfaces

The first integration will place a Vamp Action on GMGN BSC trenches cards and their BSC token chart pages, superseding the planned J7-first integration. This gives Operators a direct clone-and-relaunch workflow from BSC tokens they are already evaluating, while accepting dependence on GMGN's page structure; other GMGN chains and J7 remain possible later Token Surfaces.
